## Detailed description

Yuqi Application Copilot is a privacy-first Chrome extension for assisted job applications. It reads the visible fields on the application page you choose, resolves known answers from an authenticated private profile, attaches the active resume, and presents anything sensitive or uncertain for review.

Key capabilities:

- Detects visible application fields only after you select Auto-fill Application.
- Fills verified contact, education, experience, and profile values.
- Attaches the active, versioned PDF from the private Resume Vault.
- Matches select, radio, checkbox, and text fields across common ATS layouts.
- Explains whether each answer came from verified memory or requires confirmation.
- Uses an optional local Codex classifier for unfamiliar, non-sensitive questions.
- Keeps work authorization, compensation, EEO, signatures, and other sensitive answers review-gated.
- Never clicks the final submit button, completes CAPTCHA, accepts legal terms, or signs attestations.

The extension connects to the authenticated yuqi.site MCP platform. Personal data is used only to provide the user-requested application assistance described above. It is not sold, used for advertising, or used for unrelated credit or eligibility decisions.

An authorized yuqi.site account is required. This initial release is distributed as an unlisted owner tool while the service remains single-tenant.
